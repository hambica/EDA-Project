# Exploratory Data Analysis (EDA) Project

This project involves performing an Exploratory Data Analysis (EDA) on a dataset to uncover patterns, insights, and potential relationships using Python. The notebook walks through data loading, cleaning, visualization, and summarization.

## Project Description

The goal of this project is to explore and analyze a dataset using Python libraries such as Pandas, Matplotlib, and Seaborn. The EDA focuses on understanding data distribution, handling missing values, visualizing features, and generating statistical summaries.

##  Features

- Data loading and initial inspection
- Handling missing values and data cleaning
- Descriptive statistics
- Visualizations:
  - Histograms
  - Box plots
  - Heatmaps
  - Pair plots
- Correlation analysis

##  Technologies Used

- Python 
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
